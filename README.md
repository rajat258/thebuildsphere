# The Build Sphere

Static website for https://thebuildsphere.in, the app and web development studio of Rajat Nanavati.

Plain HTML and CSS, no build step. Hosted on GitHub Pages from the `main` branch root.

## Local preview

```
npx serve .
```

## Deploy

Push to `main`. GitHub Pages serves the root of the branch. The `CNAME` file pins the custom domain.
